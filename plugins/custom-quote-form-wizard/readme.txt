== Description ==

A custom quote form wizard integrated with Tailwind and Bootstrap.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/custom-quote-form-wizard` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Use the `[cqfw_quote_form]` shortcode to display the form on any page or post.
