== Description ==

Shared utilities library for Custom Quote Form plugins. Provides common functionality including:

* Phone number formatting (UK +44 format with WhatsApp links)
* Common validation helpers
* Email and webhook configuration

This plugin must be activated alongside:
* Custom Quote Form
* Custom Quote Form Wizard

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/custom-quote-form-shared/`
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Ensure Custom Quote Form and Custom Quote Form Wizard are also activated

== Features ==

* **Phone Formatting**: Converts UK phone numbers to international format (+44) with WhatsApp link generation
* **Email Configuration**: Shared SMTP and email settings for all quote form plugins
* **Webhook Automation**: Integration with Zapier, Make, n8n, and other automation platforms
